# UrbanFit API

UrbanFit API is an industry-standard e-commerce backend project for a fashion apparel selling platform.

## Tech Stack

- Django REST Framework
- PostgreSQL
- Docker
- JWT Authentication
- Git/GitHub

## Main Features

- User authentication
- Product catalog
- Product variants by size and color
- Cart management
- Wishlist
- Orders
- Coupons
- Reviews
- Payment-ready architecture
- API documentation
- Tests

## Environment Variables

This project uses environment variables for sensitive configuration.

Environment files are not pushed to GitHub.

Required variables will be documented here as the project grows.
